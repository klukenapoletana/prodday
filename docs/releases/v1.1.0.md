## Neu

**Teilen**
- Text aus anderen Apps, etwa eine Notiz aus NotallyX oder ein Link aus dem Browser, wird über das Teilen-Menü zur Notiz und öffnet sich sofort. Titel ist der mitgeschickte Betreff oder die erste Zeile, Formatierung wie Checklisten bleibt erhalten.

**Notizen**
- „+“ öffnet eine neue Notiz direkt im Vollbild-Editor mit Formatleiste. Die Notiz entsteht erst mit der ersten Eingabe, eine leer geschlossene Notiz hinterlässt nichts.
- Die Notizübersicht zeigt die ersten Zeilen formatiert: fett, kursiv, Überschriften, Listen, Checklisten, Code und Links.
- Ein Titel, der beim Schließen noch im Feld steht, geht nicht mehr verloren.

## Behoben

- **Sortierung springt zurück:** Eine umsortierte Checkliste oder ein verschobener Termin wurde manchmal von einem gleichzeitig laufenden Nextcloud-Abgleich zurückgesetzt.
  - Automatische Abgleiche warten jetzt, bis eine Minute lang nichts bearbeitet wurde, höchstens aber fünf Minuten.
  - Ein Abgleich, während dessen etwas bearbeitet wurde, überschreibt nichts mehr.
  - „Jetzt synchronisieren“ läuft weiterhin sofort.
- **Teilen von mehrzeiligem Text:** Er öffnete die App, legte aber nichts an.

## Hinweis

Änderungen erscheinen auf anderen Geräten jetzt etwa eine Minute nach der letzten Bearbeitung.

## Installieren

`prodday-1.1.0.apk` herunterladen und öffnen. Sie installiert sich über die Version 1.0.0, die Daten bleiben erhalten.

Prüfsumme: `prodday-1.1.0.apk.sha256`.
